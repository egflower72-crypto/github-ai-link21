## 무엇을 하는 도구인가

1. "이런 흐름을 그려 줘"라고 글로 쓰면, AI 에이전트가 도식 한 장을 HTML 파일 하나(안에 SVG 포함)로 만든다. 그림 종류는 52가지다(순서도, 단계, 타임라인, 조직도, 간트, 막대·선 그래프 등).
2. 회사 색·글꼴을 한 번 등록해 두면(프로필) 모든 도식이 같은 모양으로 나온다. PNG·SVG·PDF로 내보낼 수 있다.
3. 서버·계정·추적이 없다. 지침 문서와 예시 파일, 작은 점검 스크립트 묶음이다. 한글 라벨 규칙(Noto Sans KR, 12px 이상)이 문서에 들어 있다.

## 링크21의 어떤 일을 줄이는가

대상 업무: **교안 제작**과 **콘텐츠(블로그·SNS) 발행**에 들어가는 도식 그리기.

| | 지금 방식 【추정】 | 바뀐 방식 |
|---|---|---|
| 그리기 | 슬라이드 도구에서 상자·화살표를 손으로 배치 | 설명 3~5줄을 쓰면 초안이 나온다. 사람은 고칠 곳만 말한다 |
| 모양 맞추기 | 교안마다, 만든 사람마다 색·글꼴이 다르다 | 등록한 회사 프로필 하나로 통일된다 |
| 재사용 | 지난 도식을 찾기 어렵다 | 파일 하나라 폴더에 모아 두고 다시 쓴다 |

주당 절약 시간: **많아야 약 2.5시간 【추정, 상한】**
근거 가정: 주 10장 × (손으로 20분 − 요청·수정 5분). 장수와 소요 시간은 실제로 잰 값이 아니다. 0단계 시험에서 재서 고친다.
이 숫자는 「손으로 그린다」와만 견준 것이다. 이미 쓰는 도구(슬라이드 도구의 도형 기능, 디자인 도구의 틀, AI 채팅의 도식 기능)와는 견주지 않았다. 그쪽과 견주면 절약 시간은 이보다 작다. 「요청·수정 5분」에는 원본이 요구하는 점검·그려 보기·다시 고치기 시간이 들어 있지 않다.

줄지 않는 것: 무엇을 그릴지 정하는 일, 내용이 맞는지 보는 일. 이 둘은 계속 사람이 한다.

## 가장 작은 완성판 범위

화면
1. 요청: 설명 글 입력, 용도 선택, 「그리기」 버튼
2. 결과: 도식 미리보기, 「이렇게 고쳐 줘」 입력, PNG 내려받기
3. 모아 보기: 지난 도식 목록과 검색

API
- `POST /requests` 요청 등록
- `GET /requests/{id}` 상태와 결과 조회
- `POST /requests/{id}/revise` 수정 요청(새 판 생성)
- `GET /diagrams/{id}.png` PNG 내려받기
- `GET /diagrams` 목록

만들지 않을 것
- 블로그·SNS 자동 게시 (게시는 사람이 건별로 한다)
- 움직이는 도식, draw.io 등 외부 파일 가져오기
- 여러 브랜드 프로필 전환 (링크21 프로필 1개만)
- 슬라이드 파일 자동 삽입, 수강생용 공개 화면
- 원본 지침의 수정·재배포 (그대로 가져다 쓰고 커밋 번호만 고정)
